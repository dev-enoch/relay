# Security Policy

## Supported versions

The project currently supports the latest main branch and the latest tagged release.

## Reporting a vulnerability

Please do not disclose security issues publicly until a fix has been released.

Report vulnerabilities privately by emailing the maintainer or by opening a private security advisory through the repository's security tab if available.

Include:

- description of the issue
- affected version or branch
- reproduction steps
- impact assessment
- suggested fix or mitigation, if known

## Response expectations

We aim to acknowledge valid reports within 5 business days and provide a remediation plan as quickly as possible.

## Responsible disclosure

We appreciate responsible disclosure and will work with researchers to validate and fix issues in a timely manner.
